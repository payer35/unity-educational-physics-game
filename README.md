Educational Physics Game – Unity & C#

An interactive educational physics game developed as a university project at Boğaziçi University.

The project aims to help students understand physics concepts through interactive activities and game-based learning.

Technologies Used

Unity

C#

Visual Studio

Project Features

Interactive educational activities

Physics-based challenges

Student interaction and feedback

Game-based learning experience

How to Run

Download or clone the repository.

Open the project folder using Unity Hub.

Open the project in the Unity Editor.

Load the main game scene and press Play.

About

This project was developed as part of my undergraduate studies in Computer Education and Educational Technology at Boğaziçi University.
